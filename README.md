# Jogo de Reflexos - Apanha o Chico (MIT App Inventor) / Reflex Game - Catch Chico (MIT App Inventor)

## Sobre o Projeto / About the Project
Este projeto consiste num jogo de reflexos interativo desenvolvido no **MIT App Inventor**, criado com o objetivo de treinar a lógica de programação móvel e interações por toque.

This project is an interactive reflex game developed in **MIT App Inventor**, created to practice mobile programming logic and touch interactions.

## Como Jogar e Instalar / How to Play and Install
1. Descarrega o ficheiro **`.aia`** disponibilizado neste repositório. / Download the **`.aia`** file provided in this repository.
2. Acede à plataforma oficial do [MIT App Inventor](https://appinventor.mit.edu/) e importa o projeto. / Go to the official [MIT App Inventor](https://appinventor.mit.edu/) platform and import the project.
3. Testa a aplicação no teu telemóvel através da aplicação *AI Companion* ou gera o ficheiro APK para instalação. / Test the app on your mobile device using the *AI Companion* app or build the APK file for installation.
